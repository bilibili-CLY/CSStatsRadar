## 1. 五阶段流水线结构 (Showcase Opener Pipeline)

开场动画由原本固定的 8s 结构升级为解耦、可自定义时长的五阶段体系：
1. **比赛信息阶段（matchInfo）**：首个阶段，默认时长 6.0s。
   - 用户可自由添加、拖拽、缩放 Text 和 Image 元素；
   - 元素进场 FadeIn、退场 FadeOut（最后 800ms 内平滑淡出，时长与 FadeIn 严格一致）；
   - 支持可选的“开场黑屏渐显入场 (Fade in from black)”（前 800ms 内由全黑渐显至完全可见）；
   - 图片必须严格保持原始像素真实物理宽高比（如 1254×1254 保持 1:1，绝不可拉扁），且图片缓存必须在预览时保留以防闪烁；
   - 元素选中时显示虚线框及右上角红色实心圆内 X 删除按钮；属性检查器按选中元素动态切换显示专属编辑项（点击空白显示阶段全局设置，时长微调等冗余面板已精简移除）。

2. **阶段一（empty）**：比赛信息过渡到阶段一，Title、Subtitle、Player Image 不显示。
   - **Data Panel 目标定位**：在开场动画全阶段水平且垂直双向绝对居中（width 中心对齐 Canvas width 中心，即左边距 23%、上边距 3.5%、宽 54%、高 93%）。
   - **入场与果冻参数（已写死）**：入场时从 Canvas 水平中心与垂直高度 4/5 处（50%, 80%）启动，size 从 0 快速膨胀变大；采用 Hermite 平滑斜率连续衔接的欠阻尼弹簧振荡（冲过 1.0 时速度保持穿透，绝无减速停顿断层），微调面板已删除，固定写死为：
     - 膨胀时间比例 `expandProgress = 0.40`
     - 阻尼衰减速度 `decay = 2.5`
     - 振荡半波数 `cycles = 5.0`
     - 宽度过冲幅度 `ampW = 0.05`
     - 高度挤压幅度 `ampH = 0.05`
     - 画布每帧执行 `ctx.clearRect` 防止半透明渐变背景造成边框重叠残影。
   - **内部 Radar 与 Round Swing 联动与属性同步**：当 Data Panel 尺寸达到目标 size 的 75% 时，内部的 Radar Sub-canvas 和 Round Swing 作为一个整体也从 Canvas 水平中心与垂直高度 4/5 处（50%, 80%）启动，平滑单调放大到位并移动至目标位置（无需果冻效果）；在开场动画中**只同步缩放大小（scale）和 Y 轴位置，不同步 X 轴**（X 轴在开场动画中严格保持水平居中对齐 `width * 0.5`，与居中的 Data Panel 保持对称）；
   - **阶段一直接显示平均线与零点线**：进入阶段一时，出现的 Radar Sub-canvas 与 Round Swing 直接显示红色平均基准线，且 Round Swing 的中心点 0 点白色垂直刻度线从入场起无条件始终呈现。

3. **阶段二（新版：average 全队均值优先）**：阶段二与阶段三顺序已调转，优先展示全队平均值。
   - **Radar 平均线连续性与发光 (高保真复刻参考图)**：阶段一平均线展开后，进入阶段二透明度保持 100%（杜绝透明度跳变闪烁）。文字入场时平均线在 0.5s 内柔和亮起霓虹发光光晕；为保持 60 FPS 满帧性能严禁在每帧动画中使用昂贵全图高斯模糊 `ctx.shadowBlur`，改用 GPU 多层笔刷光晕：核心线收敛至 1.8px 细锐的高亮珊瑚粉霓虹色（`#ffa088`），外层包裹深邃柔和的绯红弥散光雾（`rgba(220, 38, 38, ...)`）及内部微弱暗红呼吸面，1:1 复刻参考图通透质感；
   - **文字字体统一规则**：所有数据文字（六角数值、Round Swing 数值等）的字体必须与项目文字字体绝对一致（`"Noto Sans SC", system-ui` 粗体），只有 `BEST` 徽标项除外（保持 `Bangers` 字体）；
   - **三步优雅向上生长动效 (间隔 0.1s，单组时长 0.5s)**：六项文字及 Round Swing 出现的动画为向上生长（位移 $+8\text{px} \to 0$ 与透明度淡入，三组间隔 0.1s 启动，每组自身生长动画时长放缓为 0.5s 以消除生硬感）：
     - 第 1 步（0.0s 启动）：`Rating`、`KPR`
     - 第 2 步（0.1s 启动）：`Multi-Kill`、`Surviving`
     - 第 3 步（0.2s 启动）：`KAST`、`ADR`、以及 `Round Swing`
   - **六项文字单行排版与防遮挡径向外推**：项目的描述（Rating、Surviving 等）和对应数值同一行显示（数值在右侧）；KPR、Surviving、ADR、KAST、Multi-Kill 正下方居中显示括号及中文别名：`(回合击杀)`、`(存活率)`、`(回合伤害)`、`(不白给率)`、`(回合多杀)`；各轴文字按所在角度方位自适应径向向外推开充分呼吸间距，杜绝遮挡 Rating、Surviving、MultiKill、ADR 等多边形与顶点。
   - **Round Swing 新布局与填充条**：
     - 条的高度在原本高度基础上**增加 50%**，并**删除条的半透明背景框**；
     - 内部数值块的**圆角删除，改为直角矩形**，动画从中心向两侧生长填充到平均线位置，动画时长同样严格同步对齐为 0.5s；
     - `"Round Swing"` 标题和数值文字并排显示在同一行的右边（居中排布在条的正下方），标题颜色采用与六角文字一致的浅灰白（`#d7dde3`）；其正下方底部用括号居中显示 `(回合影响)`。

4. **阶段三（新版：reference 外圈基准）**：外圈参考基准与指标名称显现，Swing 显示 ±5% 端点，外圈亮环发光显现并在 0.3s 内利落渐变。

5. **阶段四（outro 首位选手登场）**：均值数字淡出，首位选手数据从雷达中心及 Swing 中点展开爆发。

## 2. 核心数学与物理公式

### (1) 连贯 Cubic Hermite 弹簧曲线
在 $p < tExpand$ 期间使用三次 Hermite 插值：
$$S(u) = u^2(3 - 2u) + V_1 \cdot u^2(u - 1)$$
其中 $V_1 = ampW \cdot \omega \cdot \frac{tExpand}{1 - tExpand}$，在 $u = 1$ 时一阶导数严格等于振荡项的起始瞬时速度，穿过 1.0 时速度保持穿透，**绝无减速刹车与停顿感**。
振荡阶段幅值严格由 $1 + ampW$ 与 $1 - ampH$ 约束，杜绝过冲过头。

### (2) 六项文字生长函数
$$p = \min(1, \Delta t / 500)$$
$$E(p) = 1 - (1 - p)^3$$
$$\text{translateY} = (1 - E(p)) \times 8\text{px}$$
$$\text{opacity} = E(p)$$
$$\text{scale} = 0.92 + 0.08 \times E(p)$$
各组间隔 100ms（0.1s），单组生长时长 500ms（0.5s），优雅舒展。
